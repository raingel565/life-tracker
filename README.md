# Life Tracker

Личный трекер жизни: долги, накопления, тело, тренировки, привычки и вода. Один персонаж отражает всё сразу.

## Установка на телефон через GitHub Pages
1. Создайте на GitHub новый репозиторий, например `life-tracker`.
2. Загрузите в него все файлы из этой папки (Add file → Upload files), сохранив папку `icons`.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/life-tracker/`.
5. Откройте его в Chrome на Android → меню ⋮ → «Установить приложение».

## Обновление
Заменяете файлы в репозитории и меняете `VERSION` в `sw.js` (например `lt-v0.2.0`).
Данные на телефоне при обновлении сохраняются.

## Данные
Хранятся только на устройстве (localStorage). Очистка истории браузера их не трогает,
«Удалить данные сайтов» — стирает. Бэкап: «Ещё» → «Экспорт» (JSON), восстановление — «Импорт».
